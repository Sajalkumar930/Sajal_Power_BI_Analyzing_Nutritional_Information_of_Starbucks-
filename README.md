# ☕ Starbucks Beverage Nutrition Analysis (Power BI)

## 📌 Project Overview

This project analyzes the **nutritional information of Starbucks beverages** to help health-conscious consumers make informed choices. Using **Power BI**, the project transforms raw nutritional data into an interactive dashboard that highlights calories, sugar levels, fat content, and caffeine levels across different beverages and preparation methods.

The report allows users to explore beverage nutrition data through **interactive visuals, filters, and analytical tools**.

---

# 🎯 Objective

The goal of this project is to build a **Power BI dashboard** that:

* Analyzes nutritional values of Starbucks beverages
* Identifies beverages with **high calories, sugar, and fat**
* Helps users explore beverage nutrition interactively
* Provides insights into factors influencing **high calorie content**

---

# 📂 Dataset

The dataset contains nutritional information about Starbucks beverages, including:

* Beverage Name
* Beverage Preparation Type
* Calories
* Total Fat
* Sugar
* Protein
* Caffeine

This data enables detailed analysis of beverage nutrition.

---

# 🛠 Tools Used

* **Power BI**
* Power Query
* Data Transformation
* Data Visualization
* Business Intelligence Analysis

---

# ⚙️ Data Preparation

Several data transformation techniques were applied using **Power Query**:

* Created **conditional columns** to categorize beverages into *High*, *Medium*, and *Low calorie groups*
* Highlighted beverages with **more than 20g sugar**
* Generated a **custom column** combining beverage name and preparation type
* Cleaned and structured the dataset for visualization

---

# 📊 Dashboard Features

The dashboard includes multiple interactive Power BI visuals:

### 1️⃣ Calorie Categorization

Beverages are grouped into:

* High Calories
* Medium Calories
* Low Calories

### 2️⃣ Sugar Analysis

Beverages with **more than 20g sugar** are highlighted to identify high sugar drinks.

### 3️⃣ Beverage Description Column

A new column was created by combining:

* Beverage name
* Beverage preparation type

### 4️⃣ Navigation Using Bookmarks

Bookmarks allow users to quickly switch between views based on:

* Calories
* Fat
* Caffeine

### 5️⃣ Multi-Row Cards

Displays key nutritional metrics for selected beverages such as:

* Total Fat
* Sugar
* Protein

### 6️⃣ Top Contributors Analysis

Identifies **Top 3 beverage preparation types contributing the highest total fat**.

### 7️⃣ Drill-Through Feature

Users can drill into any beverage to view:

* Total Calories
* Total Caffeine

### 8️⃣ Q&A Feature

Users can ask natural language questions such as:

> "Which beverage has the highest caffeine content?"

### 9️⃣ Key Influencers Visual

Analyzes factors influencing **high calorie beverages**.

### 🔟 Decomposition Tree

Breaks down **calorie content** by:

* Beverage type
* Preparation method

---

# 🔍 Key Insights

Some insights derived from the analysis:

* Certain beverage preparation types significantly increase calorie content
* High sugar beverages often correspond with high calorie levels
* Preparation method plays a major role in fat and caffeine levels
* Some beverages contain significantly higher caffeine than others
